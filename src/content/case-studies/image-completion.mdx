## The Problem

Given an image with part of it missing or occluded, predict the complete image. The framework
does it **without a GAN, in a single pass**, at roughly **32 ms per 256x256 image**.

## The Framework

Co-developed with the thesis team, the framework runs in three stages:

1. **Dual-Manifold VQ-VAE**
2. **Latent Attention U-Net Mapper**
3. **Multi-Scale Detail Injection**
