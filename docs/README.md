## How the docs fit together
- `01` says **why** and **what it should feel like**.
- `02` says **what it says** (words, numbers, links).
- `03` + `05` say **what it looks like and how it moves**.
- `04` says **how it's built**.
- `06` says **in what order**, and `PROGRESS.md` says **where we are in that order**.
- `07` says **how changes are tracked**.
